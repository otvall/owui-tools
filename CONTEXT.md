# Lite Handoff Router

Маршрутизация запросов между оркестратором и сабагентами в Open WebUI. Словарь определяет язык передачи задачи и подготовки Skills для выбранной модели.

## Language

**Skill**:
Именованный набор инструкций для выполнения определённой задачи. Skill имеет идентификатор, название, описание и полное содержание инструкций; может быть прикреплён к модели.

**Skill context**:
Представление прикреплённых Skills, доступное выбранной модели: полные инструкции либо Skill manifest с возможностью загрузить инструкции по запросу.

**Skill manifest**:
Перечень доступных Skills с их идентификаторами, названиями и описаниями. Он помогает выбрать нужный Skill, но не содержит его полных инструкций.

**Workspace Model owner**:
Пользователь, которому принадлежит настроенная Workspace Model.

**Execution user**:
Пользователь, чей запрос выполняет модель.

**Handoff**:
Передача текущей задачи от оркестратора выбранному сабагенту. Выбранный сабагент продолжает выполнение задачи в рамках того же пользовательского запроса.

**Продолжение запроса**:
Следующий вызов модели при обработке того же сообщения Execution user, в том числе после выполнения Tools. Новое сообщение Execution user начинает отдельный запрос.

**Tool exchange**:
Конкретный вызов Tool и соответствующий ему результат в рамках одного запроса Execution user.

**Tool executor**:
Модель, выполнившая конкретный вызов Tool: оркестратор, сабагент или обычная модель. Tool executor может быть неизвестен, если история не позволяет определить его достоверно.

**Tool history**:
История завершённых Tool exchanges при выполнении запросов Execution user.

**Tool context**:
Подготовленная история сообщений выбранной модели, доступная её Tools в текущем продолжении запроса Execution user. Включает Skill context и Tool history, сохранённые при подготовке этого вызова модели.

**Подготовка сабагента**:
Формирование контекста выбранного сабагента для каждого вызова, включая продолжения, в рамках запроса Execution user. Учитывает доступные ему Tools, свежие прикреплённые Skills и общие правила сохранения истории. Выполняется автоматически перед дополнительными фильтрами модели; отдельное прикрепление подготовки к сабагенту не требуется.
