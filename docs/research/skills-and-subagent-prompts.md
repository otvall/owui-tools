# Routing Skills и системный промпт сабагента

Исследовано 2026-10-05. Вероятный материал из вопроса пользователя — [The Complete Guide to Building Skills for Claude](https://resources.anthropic.com/hubfs/The-Complete-Guide-to-Building-Skill-for-Claude.pdf). Сам PDF упоминает состояние распространения на январь 2026; точная дата публикации здесь не установлена.

## Рекомендации Anthropic

- Description сообщает, что делает Skill и когда его применять. Полное тело загружается по необходимости и содержит инструкции выполнения; дополнительные материалы могут загружаться отдельно. Источник: руководство, стр. 5, 10–13.
- Description следует писать в третьем лице, с конкретными задачами и условиями применения. Добавлять в инструкции стоит сведения, которых модель сама не знает; объём нужно оправдывать пользой. Источник: [Skill authoring best practices](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices).
- Проверять нужно выбор Skill, выполнение задачи и пользу относительно работы без Skill. Источник: руководство, стр. 15–17.

## Применение к owui-tools

Это рекомендация для архитектуры проекта, а не прямое требование Anthropic. Здесь routing Skills получает оркестратор для выбора адресата: см. README.md, раздел «Поток запроса», и lite_subagent_registry.py. Поэтому routing Skill может быть короткой инструкцией передачи задачи, а процедура специалиста — находиться в системном промпте его Workspace Model.

Рекомендуемое разделение:

| Место | Содержание | Читатель |
| --- | --- | --- |
| Description routing Skill | Что делает специалист и конкретные условия выбора | Оркестратор при выборе Skill |
| Тело routing Skill | Подходящие задачи, границы с соседними агентами, ожидаемый результат, инструкция вызвать lite_delegate с действительным Agent ID | Оркестратор после загрузки Skill |
| Системный промпт Workspace Model | Постоянная роль, метод работы, правила решений, проверка качества, формат ответа | Сабагент |
| Дополнительные Skills модели | Отдельные процедуры, нужные только для части задач | Сабагент по необходимости |

Обычный исполнительный Skill по Anthropic содержит процедуру работы. Routing Skill тоже содержит процедуру, но его действие — выбрать специалиста и передать задачу. Описание специализации без инструкции передачи оставляет эту часть неявной.

Проверять такую схему следует на подходящих, пограничных и неподходящих запросах, а затем отдельно проверять результат сабагента. Важные правила сабагента не должны зависеть от того, загрузил ли оркестратор routing Skill.
